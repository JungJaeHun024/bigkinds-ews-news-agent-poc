# PoC Result Summary



## 1. 검증 목적



BigKinds Excel 다운로드 데이터를 기반으로 건설산업 EWS 언론보도 후보 데이터셋 구축 가능성을 확인합니다.



## 2. 입력 데이터



| 항목 | 내용 |

|---|---|

| 원천 | BigKinds 뉴스검색 결과 Excel |

| 수집 방식 | 웹사이트 검색 후 Excel 다운로드 |

| 수집 범위 | 1일치 종합일간지 기사 |

| 데이터 규모 | 3,096건 |



## 3. 처리 결과



| 처리 단계 | 결과 |

|---|---:|

| Raw Article 적재 | 3,096건 |

| Domain Tagging | 862건 |

| Risk Event Candidate | 534건 |

| Event Summary | 10건 |

| RAG Document | 534건 |



## 4. 확인된 사항



본 PoC에서 확인한 사항은 다음과 같습니다.



\- BigKinds Excel 데이터는 EWS 언론보도 원천 데이터로 활용 가능합니다.

\- 다운로드 이후 전처리, 분류, 적재는 자동화 가능합니다.

\- 건설경기, 금융시장, 건설자재, 노동시장 4개 도메인 기준 후보 데이터셋 생성이 가능합니다.

\- LLM은 전수 판단보다 후보 기사 검토 보조 역할이 적절합니다.

\- Vector Search는 부가 기능으로 검토 가능하나, 운영 검색엔진 수준으로 사용하려면 별도 고도화가 필요합니다.



## 5. 한계



본 PoC의 한계는 다음과 같습니다.



\- 원천 수집은 웹 다운로드 기반 반자동 구조입니다.

\- 기사 원문 저장 및 재활용 범위는 저작권 검토가 필요합니다.

\- 키워드 기반 후보 탐지에는 오탐 가능성이 있습니다.

\- 운영 단계에서는 수집 주기 관리, 품질 검증, Airflow 연계가 필요합니다.

\- 전체 기사에 대한 LLM 전수 판단은 비용과 속도 측면에서 적절하지 않습니다.



## 6. 결론



본 PoC를 통해 BigKinds 기반 언론보도 데이터를 건설산업 EWS의 비정형 위험 후보 데이터셋으로 구조화할 수 있음을 확인했습니다.



이 프로젝트는 완성형 뉴스 검색엔진이 아니라, 비정형 데이터 수집 가능성 분석과 AI Agent 기반 데이터셋 구축 가능성을 검증하기 위한 실무형 PoC입니다.
